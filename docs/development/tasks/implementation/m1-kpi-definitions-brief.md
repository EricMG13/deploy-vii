**Task ID:** `dvii-impl-m1-kpi-definitions`. **Base:** `main` at the commit that lands plan v2
(the coordinator records the actual base and head at dispatch).

**Goal:** compute r14's FFO interest coverage with the user's definition and DCF and
DCF/debt with the delegated definition, so no KPI row stays undefined.

**Architecture:** two new ratio recipes in the existing canonical KPI recipe table and
one derived scalar in `_canonical_frame`. The signed-leg ratio path (`metrics._ratio`,
`_kpi_rows`) is unchanged; the `_UNDEFINED` table and its loop are deleted.

**Tech stack:** Python 3.13.15, Decimal, pydantic, pytest.

**Spec:** user answer in the Codex chat, recorded at `brief.md:158-162`: *(FFO + cash
interest paid) / cash interest paid*. DCF: [decision 0006](../../../decisions/0006-delegated-choices-and-orchestration.md)
DC-4, *DCF = FCF − dividends paid; DCF/debt = DCF / canonical total debt*; share
repurchases are not deducted. Review finding W9.

## Global constraints

- Cash interest is stored as a signed outflow (negative), as in
  `src/deploy_vii/model/metrics.py:80` (`_INTEREST = (("cash_interest", -1),)`). Interest
  paid is therefore `-1 * cash_interest`.
- FFO stays as defined: adjusted CFO − working capital change (`canonical_kpis.py:210`).
- Use the trailing-twelve-month scope, like the other coverage ratios
  (`metrics._LEVERAGE`, `metrics.py:85`).
- A missing, zero or negative denominator is Not Calculable and never produces an
  infinite or zero ratio.
- Dividends paid is an outflow account: `dividends_paid` is in
  `model/history.py` `OUTFLOW_METRICS` (read as minus its absolute value), and the
  statement key `dividends` maps to it (`model/statements.py:104`). FCF is
  `cfo_adjusted + capex` (`model/statements.py:265`). So DCF = `1 * fcf + 1 * dividends`.
- DCF is a flow scalar: `_rolling_frame` sums it over trailing quarters like FCF.
  DCF/debt uses the trailing-twelve-month scope, like `fcf_to_debt` (`metrics.py:111`).
- No stub or fake value stands in for a calculation. The report ends with `Not verified:`.

## Review Focus

1. Cash interest paid is zero or missing for the trailing year: Not Calculable (Task 1,
   step 2 test).
2. Source signs are entered as positive amounts (normalization flip): the result is
   identical (Task 1 step 1 and Task 2 step 1 add keys to the flip test).
3. Dividends paid is missing: DCF and DCF/debt are Not Calculable and never fall back to
   FCF (Task 2 test).
4. Dividends paid is a sourced zero: DCF equals FCF (Task 2 test).

def test_dcf_to_debt_uses_dcf_over_canonical_debt() -> None:
